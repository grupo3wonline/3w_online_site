Central de Ajuda

O que é o Teste Vocacional?

É uma ferramenta de autoconhecimento que avalia suas habilidades, preferências e aptidões para sugerir áreas profissionais que combinam com o seu perfil. O teste é composto por 20 perguntas sobre diferentes competências.

Como responder?

Para cada pergunta, selecione a opção que melhor descreve seu nível de afinidade com a habilidade apresentada. As opções vão de "Nada" (0 pontos) a "Muito" (5 pontos). Não existem respostas certas ou erradas.

Como o resultado é calculado?

Suas respostas são somadas por área de habilidade. As áreas com maiores pontuações são consideradas seus pontos fortes, e você recebe recomendações de carreira específicas para cada área avaliada.

Atalhos de Teclado

  • 1-6 — Selecionar opção de resposta
  • Enter — Avançar para próxima pergunta
  • Esc — Fechar esta janela

Privacidade (LGPD)

Este teste é executado 100% no seu navegador. Nenhum dado pessoal é coletado, armazenado em servidores ou compartilhado com terceiros. Apenas preferências de tema são salvas localmente (localStorage) com seu consentimento, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

Modo Escuro

Use o botão no canto superior direito para alternar entre o modo claro e escuro. Sua preferência é salva automaticamente.
