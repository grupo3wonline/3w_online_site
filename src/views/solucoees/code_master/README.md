# CodeMaster Studio

Web App robusto e performático desenvolvido com **Vue.js 3 + Vite + Tailwind CSS**.
Aplicação Mobile First, com suporte a Dark Mode, SEO otimizado e conformidade com LGPD.

## Tecnologias

- **Vue.js 3** (Composition API)
- **Vite** (Build Tool)
- **Tailwind CSS** (Styling)
- **SweetAlert2** (Alertas)
- **FontAwesome** (Ícones)
- **Vue Router** (Roteamento)

## Funcionalidades

- **Editor Online**: HTML, CSS, JS e Simulador PHP.
- **Micro-SaaS**: Funcionalidades de salvar localmente, baixar projeto e executar via Ctrl+Enter.
- **Layout Moderno**: Landing page persuasiva (Hotsite) e Interface de App focada (Dark Mode).
- **SEO & Marketing**: Otimizado com Meta Tags, OpenGraph, JSON-LD, GA4 e GTM.
- **LGPD**: Banner de cookies, Política de Privacidade e Termos de Uso.
- **Contato**: Integração com Freshdesk.

## Instalação e Execução

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Execute em desenvolvimento:
   ```bash
   npm run dev
   ```

3. Build para produção:
   ```bash
   npm run build
   ```
   Os arquivos gerados estarão na pasta `dist`.

## Estrutura

- `src/views`: Páginas (Home, Editor, Sobre, Contato, etc).
- `src/components`: Componentes reutilizáveis (Layout).
- `public`: Arquivos estáticos.
