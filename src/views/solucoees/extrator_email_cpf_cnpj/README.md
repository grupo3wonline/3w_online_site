# Extrator de Email, CPF e CNPJ

## 📋 Sobre o Projeto

Ferramenta profissional e gratuita para extração e validação de emails, CPF e CNPJ de textos. Desenvolvida pelo **Grupo 3w Online** com foco em performance, segurança e privacidade.

## ✨ Funcionalidades

- ✅ **Extração de Emails** - Encontra e extrai todos os emails válidos
- ✅ **Validação de CPF** - Extrai e valida CPFs automaticamente
- ✅ **Validação de CNPJ** - Identifica e valida CNPJs
- ✅ **Remoção de Duplicatas** - Elimina registros repetidos
- ✅ **Múltiplos Formatos de Exportação** - TXT, CSV e XML
- ✅ **Processamento Local** - 100% offline, seus dados não saem do navegador
- ✅ **Interface Responsiva** - Mobile First, funciona em qualquer dispositivo
- ✅ **LGPD Compliant** - Total conformidade com a legislação brasileira

## 🚀 Tecnologias

- **React 18** - Biblioteca JavaScript
- **TypeScript** - Type safety
- **Vite** - Build tool ultra-rápido
- **Tailwind CSS** - Framework CSS
- **Shadcn/ui** - Componentes React
- **React Router** - Roteamento
- **Font Awesome** - Ícones
- **SweetAlert2** - Alertas (via toast)

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Modo desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview
```

## 🔒 Privacidade & Segurança

**Processamento 100% Local**: Todos os dados são processados exclusivamente no navegador do usuário. Nenhum dado é coletado, armazenado ou transmitido para servidores externos.

**LGPD Compliant**: Totalmente adequado à Lei Geral de Proteção de Dados (Lei nº 13.709/2018).
